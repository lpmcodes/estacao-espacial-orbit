# Estação Espacial Orbit

Módulo de suporte de vida da estação orbital, desenvolvido como parte do
exercício de fluxo de trabalho corporativo com Git/GitHub (develop → stage → main).

## Ambientes (branches)

- **develop**: ambiente de desenvolvimento, onde novas funcionalidades são
  implementadas e testadas localmente antes de qualquer validação.
- **stage**: ambiente de homologação/testes, onde o código já revisado é
  validado antes de ir para produção.
- **main**: ambiente de produção, contendo apenas código validado e aprovado.
